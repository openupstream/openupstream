# Architecture decision records

One Markdown file per decision, numbered, never deleted. A superseded decision
gets a note pointing at the one that replaced it.

Template:

```
# ADR-NNNN: Title

Date: YYYY-MM-DD
Status: proposed | accepted | superseded by ADR-NNNN

## Context
## Decision
## Consequences
```

The table in `ARCHITECTURE.md` is the index; expand an entry into a file here
when the reasoning no longer fits in one line.
