# Security policy

openupstream runs customer data. If you find a vulnerability, please report it
privately rather than opening a public issue.

- E-mail: security@openupstream.com
- Please include steps to reproduce and the component affected.
- You will get an acknowledgement within 3 working days and a status update at
  least every 7 days until the issue is resolved.

We do not currently run a bug bounty programme. Credit is given in the release
notes if you want it.

## Scope

- This repository and the hosted service at openupstream.com.
- Out of scope: issues in upstream dependencies (report those upstream, but a
  heads-up is appreciated), denial of service by volume, social engineering.
